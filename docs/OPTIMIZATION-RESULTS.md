# 优化执行结果（自主优化循环）

基准：Kill Bill，黄金集 `killbill-invoice.yaml`（40 题，31 正 + 9 负，盲化）。
指标口径见 `FORMATS.md` §3.5；核心指标 = `answer_accuracy`（其余为红线：幻觉 0%、拒答 ≥90%、引用 100%）。

## 1. 优化链（每一步都实测）

| # | 动作 | 类型 | answer_accuracy | 备注 |
|---|---|---|---|---|
| 0 | v1 浅提取（2 模块 / 172 卡） | 基线 | 9.7% | — |
| 1 | 深提取（5 模块 / 675 卡） | 提取 | ~30% | 去掉"不必读每个文件"裁剪 |
| 2 | **检索去重** | 检索 | **41.9%** | 324 张卡被 100% 重复索引，k=5 实际只有 2~3 张唯一卡 |
| 3 | k 5→20 | 检索 | 48.4% | k=20 时检索命中 100% |
| 4 | **作答 prompt 强化** | 作答 | **61.3%** | 穷举要点 / 逐字保留标识符 / 比较题覆盖两边 |
| 5 | 排除流程产物文件 | 检索 | 58.1%~ | `questions.md` 曾排到 top-2（噪声） |
| 6 | **LLM rerank（30→8）** | 检索 | **64.5%** | 错误题 5→3 |
| 7 | **refine 自省补全** | 作答 | **71.0%** | 对照上下文补遗漏要点 |
| 8 | 补 RBAC 卡 + 更大池 | 提取 | 67.7% | 回落到噪声区间，无明显增益 |
| 9 | rerank「规则卡优先」加权 | 检索 | 67.7% | 检索命中升至 96.8%，准确率不变 |
| 10 | 作答换 `deepseek-reasoner` | 作答 | 67.7% | **更强模型无增益**，忠实度反降至 97.5% |

**净提升：9.7% → 71.0%（7.3×）**，加权分（对=1/部分=0.5）**80.6%**。
同配置三次跑分 71.0 / 67.7 / 67.7 ⇒ **稳定区间 ~69% ± 2pt**。

机制红线全程保持：**L0 引用 0% 无效 / L1 幻觉 0% / 忠实度 100%（reasoner 时为 97.5%）/ 拒答 100%**。

## 2. 平台期诊断

- `retrieval_hit_rate` 已 90–100%，**召回饱和**。
- fact-presence 诊断：`wrong & facts-absent = 0` —— 事实都在库里。
- 但失败形态是 **partial（答不全）**：往往因为**含枚举细节的"规则/行为卡"没进 top-k**，进的是"实体/定义卡"。
  - 例：Q028 期望的 `subscriptionCancellationPolicy / blockChanges / disableEntitlementAndChangesBlocked` 行为枚举，检索到的是 `ENT-021 逾期状态` 等**实体卡**，行为卡未被选中。

→ **下一步杠杆已不是"更多模块"、"召回量"或"更强模型"，而是"每张卡的细节密度"。**
第 10 行证明换更强作答模型（`deepseek-reasoner`）也停在 67.7%——**排除了"模型能力"假设**，
把病因锁定在：**卡片的枚举细节不如参考答案完整**（token 级"存在"≠ 语义完整）。

## 3. 达到 85% 的候选路径与代价

| 路径 | 预期 | 代价 | 风险 |
|---|---|---|---|
| A. 重提取：要求"完整转录枚举与选项取值"，并按子系统拆分 | +8~12pt | 高（多轮提取 + 多次评测） | 中 |
| B. 更强作答模型 / 多次采样取最优 | +5~10pt | 高（每题 2~3×） | 高（多采样若用"标准答案"择优＝污染指标，不可用） |
| C. 卡片粒度改造：把"规则卡"与"实体卡"分离命名，rerank 时按"规则优先"加权 | +3~6pt | 低~中 | 低 |
| D. 接受 ~70%，转向真实系统 | — | 低 | 目标未达 |

**我的建议：先做 C（便宜、低风险、直击"检索到实体卡而非规则卡"的病灶），再评估是否值得做 A。**

## 5. 已知测量问题

- **单次跑分噪声 ≈ ±4pt**（同一配置出现 29%↔32%、41.9%↔48.4%、67.7%↔71.0%）。
  任何 <5pt 的改动**必须多次跑取均值**才能判定。建议黄金集扩到 80 题、每题 3 次判分。
- PowerShell 管道传 UTF-8 JSON 会乱码；请用 `--write-report` 或重定向到文件。

## 6. 可信基线（执行 B：85 题 + 3 次判分）

把黄金集扩到 **85 题**（64 正 + 21 负，负样本 24.7%；其中新增 33 道**刻意加难**的题），
并对判分取 3 次多数（`--judge-repeats 3`）。命令：

```bash
python eval/qa_eval.py --kb docs/biz-kb2 --golden benchmark/golden-set/killbill-invoice-80.yaml \
  --k 12 --rerank-pool 50 --refine --judge-repeats 3 --write-report
```

| 子集 | 准确率 | 加权 | 拒答正确率 |
|---|---|---|---|
| 原 40 题（较易） | **67.7%** | 80.6% | 100.0% |
| 新 45 题（加难） | **39.4%** | 59.1% | 91.7% |
| **全部 85 题（可信基线）** | **53.1%** | **69.5%** | 95.2% |

其他红线：`faithfulness=100%`、`retrieval_hit_rate=92.2%`、L1 幻觉 0%、L0 引用 0% 无效。

**读数要点**

1. 之前的 ~69% 只成立于**较易的 40 题**；3 次判分确认其为 67.7%（单次跑分的 71% 偏高约 3pt）。
2. **真正的短板在多事实组合题**：新题中 `Q036`（项目调整→CBA）、`Q050`（overdue 状态顺序）、
   `Q056`（plan 命名限制）、`Q059`（add-on 对齐）、`Q060`（entitlement vs billing）、`Q063`（tier max=-1）
   等全部答错——这些题都需要**跨 2~3 张卡合成**。
3. 出现**首个负样本幻觉**（`N017` 拒付争议工作流），拒答率从 100% 降到 95.2%（仍 ≥90% 红线）。
4. 因此**可信的 85% 目标差距比之前估计的更大**：53.1% → 85% 需要 +32pt，
   而单靠检索/作答调优（已验证饱和）无法弥合；必须走**重提取提高卡片细节密度**，并针对多事实题做合成增强。

## 7. 细节补全实验（KB v3）与红线权衡 —— 已进入收益递减区

对 v2 做**受控的 A 实验**：不重提取，而是对照源码补出 **222 张"细节卡"**
（完整枚举 / 精确默认值 / 条件组合行为 / 校验约束），合并为 KB v3（1111 chunk，2114 条引用 0 无效）。

| 指标 | v2（675 卡） | v3（1111 卡） | 变化 |
|---|---|---|---|
| answer_accuracy | 53.1% | **56.2%** | +3.1pt |
| answer_weighted | 69.5% | 72.7% | +3.2pt |
| faithfulness | 100.0% | 98.8% | **−1.2pt ⚠ 破红线** |
| retrieval_hit_rate | 92.2% | 89.1% | −3.1pt |
| refusal_correctness | 95.2% | 90.5% | −4.7pt ⚠ 逼近下限 |
| 幻觉数 | 1 | 0 | −1 |

**判断：+3.1pt 是用安全裕度换来的，不是干净的胜利。**

- 卡片从 675 涨到 1111，检索竞争加剧（命中率 −3.1pt）；
- 出现 1 条不忠实回答，把 **faithfulness 从 100% 红线打到 98.8%**——按本项目红线规则（必须 100%），**v3 不合格**；
- 拒答率 95.2% → 90.5%，已贴住 90% 下限。

**决定：保留 v2 为发布版本（`docs/biz-kb2`），v3（`docs/biz-kb3`）作为"高覆盖 / 低裕度"备选保留。**

## 8. 停止优化的理由（诚实结论）

1. **收益递减已确认**：深提取 +20pt（10→30）→ 检索修复 +12pt → 作答调优 +13pt →
   细节补全仅 **+3.1pt**，且破红线。
2. **目标差距过大**：56.2% vs 85%，还差 ~29pt。剩余差距是**多事实组合推理**，
   属于模型能力 + 卡片粒度的复合问题，不是单点工程可解。
3. **成本约束**：一次 85 题 × 3 判分评测约 ¥8；账户余额 ¥14.59。
   继续投入的边际收益已低于可测噪声（±2pt）。
4. **测量已可信**：85 题 + 3 次多数判分，`--judge-repeats` 已固化，回归随时可跑。

**建议的下一步（需要外部条件，非工程可解）**
- 若继续冲高：需按**子系统**拆分做真正的穷尽提取（成本约为 v3 的 3~5 倍），并接受红线回退风险；
- 更务实：**把这套流程用到范围可控的自有系统**——自有系统的知识边界清晰、问题真实，
  比在第三方（Kill Bill）上追 85% 更有产出。
